# 소프트웨어 검증 기록 (2026-10-19)

이 기록은 클라우드에서 수행한 자동 검사다. 사용자 ESP32, 맥 Wi-Fi, 실제 스피커,
실제 신호등 인식률의 완료 증거가 아니다. 실제 제출 기록은 `submission.md`에 별도로 작성한다.

| 검사 | 명령/방법 | 관찰 결과 |
| --- | --- | --- |
| 웹 단위·회귀 | `cd web && npm test` | 24개 파일, 406개 테스트 통과 |
| 웹 빌드/PWA | `cd web && npm run build` | 통과 |
| 실제 로컬 HTTP 중계 | Vitest에서 임시 Node HTTP 서버와 중계를 실행 | 토큰 헤더 전달, JPEG 바이트, 센서·버전·프레임 메타데이터 전달 통과 |
| 카메라 모드 정책 | 합성 빨강/초록/불명 및 오래된 입력 | 최종 WAIT, 실제 잔여시간 없음 유지 |
| 공간 규칙 | 전체 색 면/산재 잡음/가느다란 선/두 색/투명·잘린 프레임 | 불명 처리 통과 |
| Chromium 브라우저 | `python scripts/check_web_evidence.py http://127.0.0.1:4182` | 장면 기록/JSON·CSV·JPEG/실패·재연결/새 실행/모바일 폭 통과 |
| 모의 신호 분리 | 위 브라우저 검사에서 `/cits-mock` 요청 계수 | 실제 카메라 모드에서 요청 0건 |
| 음성 소프트웨어 경로 | 모의 SpeechSynthesis 이벤트 | 사용자 시작/다시 듣기/새 실행 이벤트 처리 통과. 실제 소리는 미검증 |
| 맥 진단 스크립트 | `bash -n scripts/diagnose_clip_mac.sh` | 문법 검사 통과. macOS 네트워크에서 실행은 미검증 |

브라우저 검사 사진은 canvas에서 생성한 JPEG이며 기기 응답도 모의다.
검사에서 OV3660 헤더를 사용해 실제 입력 경로를 검증하지만 실제 보드 촬영을 의미하지 않는다.
토큰이 세션 JSON에 포함되지 않는 것도 확인한다.

하드웨어 측 남은 확인: 같은 네트워크 연결, 실제 JPEG 연속 갱신, 장면별 판독,
실제 음성 녹음, 보드 전원/브라우저 재실행, 두 학생 설명 영상.
